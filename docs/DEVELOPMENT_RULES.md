# TEJARATYAAR Development Rules

## Engineering Rules

- No direct database mutation from UI.
- Business logic belongs in backend services.
- All permissions are validated server-side.
- Sensitive actions require audit logs.
- Avoid breaking existing workflows.
- Every feature requires documentation and tests.

## Git Rules

- Small meaningful commits.
- Feature branches for major work.
- Pull request review before production merge.

## Product Rules

- Keep V1 simple.
- Do not build ERP features unnecessarily.
- Case remains the center of operations.
